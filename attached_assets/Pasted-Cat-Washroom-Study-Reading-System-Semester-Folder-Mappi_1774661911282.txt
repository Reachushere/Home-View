Cat Washroom Study Reading System - Semester Folder Mapping
  =============================================================

  This document maps out the OneDrive folder structure the player uses for each semester from Winter 2026 through Fall 2029.

  Priority Sequence: The player checks weeks in order from Week 1 to the current week, playing the earliest unfinished file first. Within each week, modules are prioritized over readings (readings are blocked until all modules for that course are complete). Courses are played in order of their configured play priority.

  Base Path: OneDrive > Files > School > 1. TMU > Courses > [Year] > [Semester] > [CourseCode - CourseName] > [Week Folder] > Module or Reading

  Player Logic Summary:
  1. Player starts from Week 1 and scans up to the current week
  2. First unlistened file found (by priority) is played
  3. Modules MUST be completed before readings for each course
  4. Course priority order determines which course is played first
  5. Partially-listened files resume from where they left off

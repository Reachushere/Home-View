### OneDrive endpoints — exact names (do not invent)
- `/api/onedrive/status?verify=1` → real token check (60s cache, `?force=1` to bust). Returns {connected, tokenWorks, oneDriveFolderConfigured}.
- `/api/onedrive/list-raw?path=<urlencoded>` → unfiltered subfolder/file listing. Bypasses Graph SDK (which throws cryptic "startsWith" errors on edge paths). Already path-normalizes leading/trailing/double slashes.
- `/api/onedrive/auth` (POST) → device-code flow. Returns user_code + verification_uri. Bryn must physically open microsoft.com/link and type the code. You CANNOT do this step.
- `/api/onedrive/list?path=...` → filtered (used by Library/week sync).
- DO NOT invent: `/folder-children`, `/children`, `/list-folder`. They 404.

### Token refresh / keep-alive (server/index.ts ~647)

### File text extraction & Library search
- `files` table columns: id, folder, original_name, display_name, object_path, content_type, size, extracted_text, prepared_audio_paths, total_chunks, listened, last_chunk_index, checked_chunks, tts_audio_url, tts_generated_at, prepared_at, created_at. **NO `name` column** — use `original_name` or `display_name`.
- `extracted_text` is NULL until first read. Trigger lazy extraction by `GET /api/files/:id/text` — extracts, caches in DB, returns `{text}`.
- Library search (~routes.ts:5605) only finds files where `extracted_text IS NOT NULL`. If Bryn says "search isn't finding X", first check `SELECT id, folder, LENGTH(extracted_text) FROM files WHERE folder = '<week>-<course>-module'` and trigger extraction for any with NULL.
- Folder naming convention: `week-N-<courseCodeLower>-<type>` where type is `module` or `reading`. Examples: `week-1-cfnf400-module`, `week-11-cppa122-reading`.

### App Architecture Summary ###

**Frontend**: React + TypeScript, Vite bundler, shadcn/ui components, TanStack Query v5, wouter routing, Tailwind CSS
**Backend**: Express.js + TypeScript, Drizzle ORM, PostgreSQL
**Shared types**: shared/schema.ts (Drizzle tables + Zod insert schemas)
**Runs on**: Raspberry Pi at :5000 (PM2 managed), also developed on Replit

### Database Tables ###
tasks, subtasks, semesters, semester_settings, files, file_pages, sticky_notes, degree_tracking_data, feedback_notes, app_state, announcements, scheduled_alexa_announcements, ha_automations, notepad_notes, notepad_attachments, shift_schedule, weather_alert_history

### Key Files ###
- client/src/pages/dashboard.tsx — Main dashboard UI (very large, always use offset/limit when reading)

### Coding Conventions ###
- Auth levels: 5747=full (Bryn), 4201=partner, 1010=guest
- Timezone: Always America/Toronto, use easternNow/easternDateStr/easternHour/easternMidnight
- Semester key format: w2026 (winter), ss2026 (spring-summer), f2026 (fall)
- Email: FROM homeworkbryn@gmail.com TO bryn.kai-hendricks@outlook.com via sendGmail()
- Styling: Avenir font, gradient headers, rgba() for SVG stopColor (never 8-digit hex)
- API pattern: app.get/post/patch/delete("/api/...", async (req, res) => { ... })
- DB operations: Always through storage interface (storage.createTask, etc.)
- Frontend data: useQuery({ queryKey: ["/api/..."] }) with pre-configured fetcher
- Mutations: useMutation + apiRequest + queryClient.invalidateQueries
- Never add previous-week fallback logic
- Never use the word "anyway" in responses
- Do not rename Degree Tracker/Diploma Tracking pages

### 2026-04-16 — Bottom tab labels (Homework/Notes)
- Where: client/src/pages/dashboard.tsx ~line 20734 (Homework tab) and ~20770 (Notes tab)
- What: Position uses calc() offset (e.g. `+195px`, `+140px`), NOT raw pixel left. Label font is 12px / weight 600 / fill 0.95.
- Why: Don't try to set `left: 195` — it's a calc expression. Read first.

### 2026-04-16 — Homework↔Notes swap animation
- Where: client/src/pages/dashboard.tsx (4 swap handlers) + client/src/index.css keyframes
- What: Outgoing panel uses `hwShrinkToTab` keyframe + `hw-anim-shrink` class; incoming uses `hwGrowFromTab` + `hw-anim-grow`. All 4 handlers must be coordinated or animation breaks.
- Why: If you add a new swap entry point, mirror the same coordination or it'll feel janky.

### 2026-04-16 — BrynAssist white-on-white text bug
- Where: client/src/components/AiCommandWizard.tsx (bubble color resolver, ~line 1290) + server/aiCommandTools.ts update_app_theme
- What: When wizardTextColor luminance ≈ bubble bg luminance, text becomes invisible. Two guards: (1) frontend ignores wizardTextColor if luminance matches bg, (2) server-side update_app_theme rejects same-luminance combos with actionable error.
- Why: Always pair text color changes with the bg they'll sit on. Use wizardUndo param to roll back.

### 2026-04-17 — BrynAssist thinking trace UI
- Where: client/src/components/AiCommandWizard.tsx Message interface (~267) + bubble renderer (~1277)
- What: New 'thinking' role renders italic muted text with brain emoji + "THINKING" label, NOT a system bubble. SSE event type 'thinking' → push role:'thinking' message.
- Why: Don't pipe thinking events through 'system' role — different visual treatment.

### 2026-04-XX — Pi deploy flow
- Where: ~/Home-View/deploy.sh on Pi (172.24.1.204)
- What: Pi runs `git pull && ./deploy.sh` which always wipes dist/ and rebuilds. After deploy, hard-refresh browser (Ctrl+Shift+R) to bust cache.
- Why: HMR doesn't reach the Pi browser — manual refresh required.

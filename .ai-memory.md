### App Architecture Summary ###

**Frontend**: React + TypeScript, Vite bundler, shadcn/ui components, TanStack Query v5, wouter routing, Tailwind CSS
**Backend**: Express.js + TypeScript, Drizzle ORM, PostgreSQL
**Shared types**: shared/schema.ts (Drizzle tables + Zod insert schemas)
**Runs on**: Raspberry Pi at :5000 (PM2 managed), also developed on Replit

### Database Tables ###
tasks, subtasks, semesters, semester_settings, files, file_pages, sticky_notes, degree_tracking_data, feedback_notes, app_state, announcements, scheduled_alexa_announcements, ha_automations, notepad_notes, notepad_attachments, shift_schedule, weather_alert_history

### Key Files ###
- client/src/pages/dashboard.tsx — Main dashboard UI (very large, always use offset/limit when reading)
- client/src/components/ — Shared React components
- client/src/pages/mobile/ — Mobile-optimized version at /m
- server/routes.ts — ALL API endpoints (very large, use search_code)
- server/storage.ts — Database CRUD operations (IStorage interface)
- shared/schema.ts — Database schema definitions + Zod schemas
- server/aiCommandTools.ts — AI wizard tool definitions
- client/src/index.css — Theme CSS variables and Tailwind config
- server/gmail.ts — Email sending (sendGmail)
- server/timezone.ts — Eastern timezone helpers

### Coding Conventions ###
- Auth levels: 5747=full (Bryn), 4201=partner, 1010=guest
- Timezone: Always America/Toronto, use easternNow/easternDateStr/easternHour/easternMidnight
- Semester key format: w2026 (winter), ss2026 (spring-summer), f2026 (fall)
- Email: FROM homeworkbryn@gmail.com TO bryn.kai-hendricks@outlook.com via sendGmail()
- Styling: Avenir font, gradient headers, rgba() for SVG stopColor (never 8-digit hex)
- API pattern: app.get/post/patch/delete("/api/...", async (req, res) => { ... })
- DB operations: Always through storage interface (storage.createTask, etc.)
- Frontend data: useQuery({ queryKey: ["/api/..."] }) with pre-configured fetcher
- Mutations: useMutation + apiRequest + queryClient.invalidateQueries
- Never add previous-week fallback logic
- Never use the word "anyway" in responses
- Do not rename Degree Tracker/Diploma Tracking pages
